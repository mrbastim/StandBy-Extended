# История изменений

[English](CHANGELOG.md) | [Русский](CHANGELOG.ru.md)

Здесь описываются существенные изменения StandByMode.

## 1.1.0 — StandByMode

### Несовместимое изменение

- **Новый идентификатор Android-приложения:** `com.mrbastim.standbymode` вместо `com.mrbastim.standby.extended`. Android устанавливает StandByMode **как отдельное приложение, а не как обновление v1.0.6**. Старые настройки не переносятся. Если старая версия больше не нужна, её можно удалить вручную.
- Новое название приложения и GitHub-репозитория — **StandByMode**. Kotlin-код и тесты перенесены в новый пакет.

### Добавлено

- Локальный таймер (1–180 минут), Pomodoro (25/5 минут с ручной сменой фаз) и секундомер — отдельные виджеты и инструменты рядом с полноэкранными часами.
- Сохранение расположения инструмента слева или справа и отдельное отключение будильника в виджетах и календаре.
- Запоминание выбранной карточки каждой колонки; прокручиваемый редактор позволяет добавить все 11 уникальных типов виджетов независимо с каждой стороны.

### Изменено

- Более понятные настройки на русском, английском и турецком языках, группировка настроек экрана и прокручиваемый выбор города.
- Адаптивная раздельная компоновка часов и инструмента, кнопки по центру и запасной вариант для узких экранов; в Ambient кнопки таймеров скрываются.
- Версия `1.1.0`, Android `versionCode 8`.
- Новый APK стабильного релиза: `standbymode.apk`; dev-сборки: `standbymode-dev.apk`.
- Проверка релиза допускает однократную смену пакета при переходе с v1.0.6, но по-прежнему требует увеличения `versionCode`.

### Исправлено

- Обновление устаревших и истёкших данных о ближайшем будильнике; исключение известных напоминаний системного календаря. На отдельных прошивках сведения всё ещё могут быть неточными; отображение будильника можно отключить.
- Восстановление активных карточек при повторном открытии и перестановке.
- Восстановление локальных таймеров при пересоздании приложения в пределах подтверждённой сессии загрузки; сброс при перезагрузке или неизвестном счётчике загрузок.

### CI и релизы

- Единый источник версии, проверка метаданных APK, Smoke-тесты API 28/35 и проверка DreamService на API 35.
- Установочные debug APK в артефактах pull request.
- До трёх дополнительных попыток при подтверждённых сетевых ошибках загрузки Robolectric в PR, dev и stable; обычные ошибки тестов, Lint и компиляции по-прежнему останавливают сборку.

### Известные ограничения

- Завершение таймера отображается визуально; фоновые уведомления и автоматическое переключение фаз Pomodoro не предусмотрены.
- Защита OLED пока использует периодический сдвиг и управление яркостью; экспериментальный адаптивный алгоритм в этот релиз не входит.

## 1.0.6

### Добавлено

- Кнопки выхода из системной заставки и автоматического StandBy внутри приложения. Касание показывает кнопку на пять секунд. Выход из автоматического режима возвращает настройки до следующего сеанса активации.
- Москва, Санкт-Петербург, Казань, Екатеринбург, Новосибирск и Владивосток в общем списке городов для часов и погоды.

### Изменено

- Понятные названия и описания настроек Protection 2.0, значения рядом с названиями, читаемые интервалы времени, готовые задержки затемнения и точный ввод.
- Обновлены английские, русские и турецкие подписи. Добавлены превью для компактных альбомных экранов и увеличенного системного шрифта.

### Исправлено

- Секунды часов помещаются в колонку режима двух виджетов, в том числе при увеличенном шрифте.
- Ползунки яркости удерживают яркость ожидания в пределах яркости при запуске.


### Исправлено

- Уменьшение задержки бездействия учитывает прошедшее время после недавних кадров и во время затемнения.
- Переключатель адаптации освещённости недоступен без TYPE_LIGHT.
- Подпись release вынесена из Gradle в отдельную job с проверкой владельца запуска и environment; защита ветки и секретов требует настройки владельцем.
- Перед публикацией CI дважды запускает minified release на эмуляторе API 28.

- Падение release при запуске (`LocalLifecycleOwner not present`): R8 удалял мост reflection Compose 1.6, используемый Lifecycle 2.8.

### Добавлено

- Интеграционная ветка `dev` с одним обновляемым prerelease (`dev`) после успешных проверок, без замены стабильного Latest. Стабильный APK — `standby-android-extended.apk`, разработческий — `standby-android-extended-dev.apk`.
- Автоматический Night Mode по датчику только при устойчивой почти полной темноте и заданной минимальной яркости.

- Английская и русская версии README, руководства для участников, документации по архитектуре, проверкам и публикации.
- AMOLED Protection 2.0 с независимой яркостью окна: 35% при запуске и 8% минимум; настраиваемая задержка бездействия 120 с и переход 12 с.
- Общая политика экрана Activity/DreamService, очистка ресурсов жизненного цикла, плавное восстановление при касании и необязательная адаптация TYPE_LIGHT с фильтрацией.
- Дополнительный таймер бездействия, отпускающий удержание экрана Activity либо завершающий DreamService с учётом поведения сна Android/OEM.
- Раскрываемый раздел «Экран и защита AMOLED» с сохраняемыми настройками и строками на английском, русском и турецком.
- Тесты чистой политики и фильтра, а также проверки окна, датчика и жизненного цикла Robolectric на API 28 и 35.
- Описание архитектуры и матрица ручных проверок; предотвращение выгорания физического AMOLED не гарантируется.

- Android CI для unit-тестов, Lint и сборки debug.
- Unit-тесты активации, инвариантов списков виджетов и резервного выбора темы.
- Ресурсы интерфейса на английском и турецком.
- Подписи специальных возможностей и увеличенные области нажатия в редакторах режима ожидания.
- Конфигурация Dependabot и контрольный список проверки pull request.
- Выбор города вторых часов с корректной обработкой часовых поясов.
- Виджет ближайшего будильника на основе системного расписания Android без дополнительного разрешения.
- Лицензия MIT для повторного использования и распространения.
- Необязательный виджет текущей погоды Open-Meteo для выбранного города мирового времени.
- Компактная карточка обратного отсчёта будильника в левом нижнем углу второй страницы часов.
- Уменьшенная плашка отсчёта будильника с цветом фона.
- Минимальный индикатор будильника без контейнера, только со значком часов и отсчётом.

### Изменено

- Ambient сохраняет выбранную дневную/ночную палитру; часы и отсчёт будильника обновляются по минутам без изменения сохранённых настроек.
- Pixel Shifting сохраняет пять позиций ±3 dp с интервалом 60 с; по краям всего содержимого страниц, включая музыку, зарезервировано место.
- Keep Awake и Screen Timeout используют общую политику; конечные таймеры перезапускаются при реальном взаимодействии.

- Namespace and application ID are now `com.mrbastim.standby.extended`.
- В release-сборках включено сокращение кода и ресурсов.
- Редактор стека и строки настройки лучше адаптируются к компактным альбомным экранам.
- Описание ночного режима учитывает выбранную ночную тему, а не обещает фиксированную красную палитру.

### Исправлено

- Затемнение по бездействию больше не включает Crimson Night: ручной Night Mode и подтверждённая датчиком темнота независимы от таймера.
- Фильтр освещения обновляется между событиями датчика типа on-change и корректно восстанавливает яркость после одного измерения нового постоянного освещения.

- После пересоздания Activity заново привязываются принадлежащие ей наблюдатели системного состояния, чтобы сохранённый ViewModel не оставался с остановленными потоками.

- Отсутствие настроек заставки у OEM больше не приводит к падению.
- При восстанавливаемых ошибках чтения DataStore используются безопасные значения по умолчанию.

### Известное ограничение установки

- Google Play Защита может блокировать установку скачанного APK из-за доступа к уведомлениям для управления музыкой. Подписанный разработческий APK установлен и запущен через отладку Android Studio на realme XT с Android 13.
